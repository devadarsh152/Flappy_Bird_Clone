# 2D Flappy Bird Remake (Godot 4)

A 2D remake of the classic Flappy Bird game developed in **Godot 4** using **GDScript**. Built to demonstrate core 2D game loops, impulse physics handling, and signal-driven score management.

## 🕹️ Key Features & Implementation Details
* **Game Loop & Flow Control:** Implemented lightweight game states (Start, Playing, Game Over) managed through clean conditional flags and event triggers.
* **Procedural Spawner:** Programmed dynamic pipe obstacle spawning using `Timer` nodes and randomized vertical offsets.
* **Physics & Collisions:** Configured 2D body physics, gravity scaling, and impulse-based flap mechanics with precise collision detection.
* **Score Tracking:** Utilized Godot's **Signal system** to decouple score calculation from obstacle passage.

## 🛠️ Built With
* **Engine:** Godot Engine 4.x
* **Language:** GDScript
